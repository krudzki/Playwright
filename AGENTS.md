# AGENTS.md

## Language policy (English-only code and docs)

All first-party code and documentation in this repository must be written in
English. This applies to every contribution, including changes made by AI
coding agents.

- **Identifiers** - variable, function, class, and file names must be English.
- **Comments and docstrings** - all source comments and docstrings in English.
- **User-facing strings** - UI text, log messages, and API responses in English.
- **READMEs and docs** - all Markdown/documentation files in English.
- Do not introduce new non-English words or sentences anywhere in tracked files.

Existing content that violates this policy should be translated to English as
part of any change that touches it.
